# **San Francisco Bay Water Quality Database**

A relational database project built from EPA Water Quality Portal data for a subwatershed of the San Francisco Bay (HUC12: 180500041002). The goal is to clean raw environmental monitoring data, load it into a structured DuckDB database, and run reproducible analyses of water quality patterns.

---

## **Repository Purpose**

This repository contains:

- Cleaned water quality data from the Water Quality Portal  
- SQL scripts to create a relational database (station → activity → result)  
- Python scripts and notebooks for data cleaning, exploration, and visualization  
- A reproducible workflow for building and querying a DuckDB database  

The project demonstrates database design, environmental data processing, and SQL‑based analysis.

## **Data Access**

This project uses publicly available data from the **Water Quality Portal** filtered by HUC12.

Download raw CSVs directly:

- Station: `https://www.waterqualitydata.us/data/Station/search?huc=180500041002&mimeType=csv` [(waterqualitydata.us in Bing)](https://www.bing.com/search?q="https%3A%2F%2Fwww.waterqualitydata.us%2Fdata%2FStation%2Fsearch%3Fhuc%3D180500041002%26mimeType%3Dcsv")  
- Activity: `https://www.waterqualitydata.us/data/Activity/search?huc=180500041002&mimeType=csv` [(waterqualitydata.us in Bing)](https://www.bing.com/search?q="https%3A%2F%2Fwww.waterqualitydata.us%2Fdata%2FActivity%2Fsearch%3Fhuc%3D180500041002%26mimeType%3Dcsv")  
- Result: `https://www.waterqualitydata.us/data/Result/search?huc=180500041002&mimeType=csv` [(waterqualitydata.us in Bing)](https://www.bing.com/search?q="https%3A%2F%2Fwww.waterqualitydata.us%2Fdata%2FResult%2Fsearch%3Fhuc%3D180500041002%26mimeType%3Dcsv")  

Place the files in `data_raw/`:

```
station.csv
activity.csv
result.csv
```

Run the cleaning script:

```
python data_cleaning.py
```

Then build the database:

```
duckdb < create_database.sql
```

## **How to Reproduce the Analysis**

1. Download raw WQP data into `data_raw/`  
2. Run `data_cleaning.py` to generate cleaned CSVs  
3. Execute `create_database.sql` to build the DuckDB database  
4. Open the notebooks to explore and visualize results
